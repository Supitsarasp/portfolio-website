เพิ่มรูปกิจกรรม

เลือกรูป เขียนคำบรรยาย แล้วบันทึกลงโปรเจกต์ รูปจะอยู่ครบเมื่อเปิดเว็บครั้งถัดไป

2. เลือกรูปและเขียนคำบรรยาย

รองรับ JPG, PNG และ WebP สูงสุด 6 รูปต่อกิจกรรม ไฟล์ต้นฉบับไม่เกิน 15 MB ต่อรูป ระบบจะย่อขนาดด้านยาวให้ไม่เกิน 1,600 พิกเซลและแปลงเป็น JPG ให้เอง

รูปแรกเป็นรูปหลัก ใช้ปุ่มเลื่อนไปก่อน/หลังเพื่อเปลี่ยนลำดับ

ยังไม่มีรูปในกิจกรรมนี้ เลือกรูปเพื่อเริ่มต้น

ดูผลในหน้าเว็บ ↗

เมื่อจะอัปเดตเว็บออนไลน์

  1. กดบันทึกในหน้านี้ให้เรียบร้อย
  2. กลับไปที่โฟลเดอร์โปรเจกต์ แล้วสร้างเว็บด้วย npm run build
  3. นำโฟลเดอร์ dist ชุดใหม่ขึ้นโฮสต์เดิม รูปจะมองเห็นได้จากเครื่องของผู้เข้าชมด้วย

หน้านี้เปิดได้เฉพาะตอนรันเว็บในเครื่องด้วย npm run dev จึงไม่มีปุ่มแก้ไขสำหรับผู้ที่เปิดเว็บออนไลน์
