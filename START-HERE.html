เปิดเว็บ แก้ข้อมูล และเพิ่มรูป
โดยไม่ต้องไล่แก้หลายไฟล์

มี 8 โปรเจกต์ 2 กิจกรรม 7 ใบรับรอง และ 5 กลุ่มทักษะ พร้อมตัวตรวจข้อมูลก่อน Build

1. เปิดเว็บครั้งแรก

  1. แตก ZIP ทั้งหมดเป็นโฟลเดอร์ก่อน
  2. ติดตั้ง Node.js รุ่น ^20.19.0 หรือ >=22.12.0
  3. ดับเบิลคลิก START-WEBSITE.bat
  4. ครั้งแรกต้องใช้อินเทอร์เน็ตเพื่อรัน npm.cmd ci

อย่าดับเบิลคลิก index.html เพราะ React ต้องรันผ่าน HTTP และอาจเห็นหน้าขาว

2. แก้ข้อมูล

แก้ชื่อ อีเมล ทักษะ การ์ด ลิงก์ และ PDF ที่ src/data/portfolioContent.json แล้วรัน npm.cmd run validate:content ตัวตรวจจะแจ้ง field ที่ผิดหรือ local asset ที่หายก่อน Build

JSON ไม่เปลี่ยน Resume PDF อัตโนมัติ หากแก้ Resume ให้ใช้ public/files/Resume-TH.html แล้วพิมพ์เป็น PDF ใหม่

3. เพิ่มรูปกิจกรรม

  1. เปิดเว็บในโหมด Dev
  2. ไปที่ “กิจกรรม” แล้วกด “เพิ่ม / จัดการรูปกิจกรรม”
  3. เลือก JPG/PNG/WebP สูงสุด 6 รูปต่อกิจกรรม ไฟล์ต้นฉบับไม่เกิน 15 MB
  4. เขียนคำบรรยาย เรียงลำดับ แล้วกดบันทึก
  5. Build และอัปโหลด dist ชุดใหม่เพื่อให้เว็บออนไลน์เปลี่ยน

เครื่องมือแก้รูปเปิดเฉพาะในเครื่องและมีมาตรการป้องกันการเขียนจาก Host/Origin/Token ที่ไม่ถูกต้อง

4. สร้างเว็บ Production

ดับเบิลคลิก BUILD-WEBSITE.bat หรือใช้ npm.cmd run test แล้ว npm.cmd run build

นำเนื้อหาภายใน dist ขึ้น Static Host ห้ามนำ Source ZIP ไป deploy ตรง ๆ

Contact และความเป็นส่วนตัว

ฟอร์มจะเตรียมข้อความและเปิดแอปอีเมล ผู้ใช้ต้องกดส่งเอง เว็บไซต์ไม่แสดงผลส่งสำเร็จปลอมและยังไม่มี Backend ส่งตรง ข้อมูลเพิ่มเติมอยู่ในส่วน “ข้อมูลความเป็นส่วนตัว” บนหน้าเว็บ
